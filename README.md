# Комментарии

SPA-приложение для публикации и просмотра комментариев с поддержкой вложенных ответов, вложений и защиты от спама.

## Возможности

### Комментарии

- добавление корневого комментария через форму
- ответ на любой комментарий — без ограничения глубины вложенности
- список корневых комментариев с пагинацией (25 на страницу)
- сортировка по имени пользователя, email и дате (по возрастанию и убыванию)
- по умолчанию новые комментарии отображаются первыми (LIFO)

### Форма добавления

- **User Name** — латинские буквы и цифры (обязательно)
- **E-mail** — в формате email (обязательно)
- **Home page** — URL (необязательно)
- **CAPTCHA** — проверка по изображению (обязательно)
- **Text** — текст сообщения с ограниченным набором HTML-тегов: `<a>`, `<code>`, `<i>`, `<strong>`
- **Файл** — изображение (JPG, GIF, PNG) или текстовый файл TXT (необязательно)

### Вложения

- изображения автоматически уменьшаются до 320×240 px с сохранением пропорций
- текстовые файлы — не более 100 КБ
- просмотр вложений в интерфейсе

### Безопасность

- санитизация HTML и защита от XSS
- параметризованные запросы к БД через Prisma (защита от SQL-инъекций)
- валидация данных на сервере и клиенте
- JWT-авторизация для действий модератора (удаление комментариев)

### Дополнительно

- предпросмотр сообщения перед отправкой
- панель вставки разрешённых HTML-тегов
- обновление списка комментариев в реальном времени (WebSocket)
- кэширование списка и CAPTCHA (Redis)
- асинхронная обработка изображений (очередь задач)

## Стек

- **Backend:** NestJS, Prisma, PostgreSQL, Redis, BullMQ
- **Frontend:** React
- **Инфраструктура:** Docker Compose

## Структура репозитория

```
├── docker-compose.yml   # PostgreSQL, Redis, API, клиент
├── database/            # SQL DDL
├── server/              # REST API (NestJS)
└── client/              # SPA (React)
```

## Запуск

### Требования

- Node.js 18+
- Docker и Docker Compose

### 1. Переменные окружения

```bash
cp server/.env.example server/.env
```

### 2. База данных и Redis

```bash
docker compose up -d
```

### 3. Сервер

```bash
cd server
npm install
npx prisma generate
npm run prisma:migrate
npm run prisma:seed
npm run start:dev
```

API доступен по адресу: http://localhost:4040

### 4. Проверка

```bash
curl http://localhost:4040/health
```

Ответ при успешном запуске:

```json
{
  "status": "ok",
  "db": "ok",
  "redis": "ok"
}
```

### Полный запуск в Docker

```bash
docker compose up --build
```

Поднимает все сервисы: PostgreSQL, Redis, API и клиент.

## API

- `GET /health` — состояние сервиса
- `GET /comments` — список корневых комментариев (`?page=1&limit=25&sortField=createdAt&sortOrder=desc`)
- `GET /comments/:id` — один комментарий с деревом ответов
- `POST /comments` — создать комментарий
- `POST /comments/:id/replies` — ответить на комментарий
- `POST /comments/preview` — предпросмотр текста (XSS-safe HTML)
